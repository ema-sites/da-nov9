# carousel-promo

Custom **carousel** block. Purpose: Full-width rotating promotional banners at the top of the page.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 = banner image (mandatory; may be wrapped in a link for image-only slides); cell 2 (optional) = overlay text: heading, description, CTA link.

## Supported variations

No variations.
