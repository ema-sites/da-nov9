# cards-game-tile

Custom **cards** block. Purpose: Featured games and promotions tile grid.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 = image (plus optional text lines shown as an overlay strip on the image); cell 2 = title (heading or first line), description, optional draw details, CTA link as the last link-only paragraph; cell 3 (optional) = badge text such as NEW.

## Supported variations

No variations.
