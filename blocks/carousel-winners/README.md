# carousel-winners

Custom **carousel** block. Purpose: Recent-winners spotlight slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional first row with a single image cell = block background graphic; then one row per winner: cell 1 = winner photo (image only), cell 2 = name, location, CTA link, cell 3 (optional) = game logo image, label (e.g. Winner) and prize amount (last line).

## Supported variations

No variations.
